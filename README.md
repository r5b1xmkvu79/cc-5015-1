# 机械网格修复工具

针对合成三角网格（STL / OBJ / PLY）的缺陷检测、受限修复、复核与审计工具。Qt 桌面界面，几何内核不依赖第三方网格库。

## 设计原则

1. **先检测，后修复；修复前保留原网格。** 导入即保存一份不可变的 `original` 快照，所有操作只修改工作副本。
2. **自动操作只作用于明确选择的缺陷。** 每个修复都要求用户选中具体的面/顶点/开口环/缺陷实例；没有"一键全修"。
3. **位置相近 ≠ 应焊接。** 重合/邻近顶点只报告，默认不焊接。焊接以模型单位表达阈值，并拒绝间距超过阈值的顶点组；薄壁两侧的重合点不会被自动合并。
4. **无法可靠判断内外方向的部分标"待确认"。** 只有封闭（每条边恰好两面）组件才用有符号体积判断朝向；开放壳体的朝向标记为不确定，工具不会擅自翻转。所有待确认事项（开口、朝内组件、邻近顶点、非流形实体、方向不明的开放组件）都列在缺陷面板的"待确认"框内，并原样写入审计 JSON 的 `pending_confirmations`。
5. **补洞有尺寸与形状边界。** 补洞只在明确的边数、周长、段长、平面偏差、简单多边形限制内进行；设计开口与破损开口外观相同，超限即拒绝，需人工显式放宽并说明理由。
6. **每次修改留下完整记录。** 记录操作类型、全部参数、受影响顶点/面、新增/删除元素、时间戳与理由；可逐步撤销/重做，可回退到任意历史点。
7. **复核以重新检测为准。** 导出/修复后重新跑一遍检测，按缺陷指纹对比"已解决/遗留/新增"，并报告面积、体积、包围盒、拓扑指标变化。文件能打开不算修复成功。
8. **可溯源。** 导出文件内嵌来源 ID，并写出 `.meshrepair.json` 审计旁件（基线缺陷指纹、操作历史、复核报告）。重新加载后能把当前缺陷追溯到最初导入时的缺陷。

## 缺陷类型

| 类型 | 说明 | 是否自动修复 |
|---|---|---|
| 退化面 | 零面积、重复索引、极狭长 | 删除选中面 |
| 重复面 | 相同顶点三元组（同向/反向） | 删多余面，保留面写入记录 |
| 非流形边 | ≥3 面共享一条边 | 按面扇/边拆分，保面不删（需选中实例） |
| 非流形顶点 | 面扇不连通的蝴蝶结顶点 | 按面扇复制顶点分离（需选中实例） |
| 绕向冲突 | 共享边被同向使用 | 翻转冲突面（需确认） |
| 整体朝内组件 | 封闭组件体积为负 | 整体翻转（需确认） |
| 重合/邻近顶点 | 位置在阈值内 | **仅报告**，焊接需人工确认 |
| 开放边界 | 边界环 | 补洞（受尺寸/形状限制，需确认） |
| 孤立顶点 | 未被面引用 | 移除（可撤销） |

## 运行

```bash
# 首次在无系统 Qt 图形库的主机上运行（脚本会自动加入本地库路径）
./scripts/run.sh

# 指定单位导入
./scripts/run.sh model.stl
```

界面布局：

- **中间画布**：左键旋转、右键/中键平移、滚轮缩放、`B` 框选、`F` 适配视图。缺陷以红/橙色高亮，新补的面显示为绿色。
- **左栏「缺陷」**：按类别列出检测结果，双击定位并在画布上选中对应几何。
- **左栏「修复」**：所有可变操作。焊接、翻转组件、补洞会弹出确认框，要求说明理由。
- **右栏「修复历史」**：每条修改可双击回退到该步之前。
- **右栏「复核报告」**：`F6` 生成，列出每类缺陷的前后数量、几何变化与遗留问题。
- **右栏「检测设置」**：单位、重合阈值、退化尺寸、长宽比上限；应用后重新检测。

`文件 → 导出修复结果` 同时写出网格、审计 JSON 与旁件。

## 两种修复路线（策略实验）

仓库内同时实现了两条缺陷处理路线，供对照而不是二选一：

| 路线 | 做法 | 典型取舍 |
|---|---|---|
| 直接改局部连接（`local_connections`） | 每个缺陷就地最小改动；能补的洞先补 | 可交付部分结果，超限洞保留 |
| 先建有效拓扑再修补（`topology_first`） | 先拆非流形交汇并清点全部环，再统一修补 | 有一个环超限就整体不落地 |

两条路线共用同一非流形拆分内核（按面扇复制顶点 + 拆边，**不删除任何非冗余面**）。
实验入口：

```bash
python3 scripts/strategy_experiment.py
```

它把多洞与非流形交汇两个基准的拓扑不变量与属性变化复算到
`artifacts/strategy_experiment.json` / `.md`，并附
`artifacts/strategy_experiment_notes.md` 记录结论、处理边界与**单列的待验假设**。
不变量与属性变化都由 `mesh_repair/core/invariants.py` 的代码计算，文档不手填数字。

## 图形入口与生产接点

修复内核通过 `mesh_repair/core/production.py` 接到视窗：

- 画布中选中坏面 → 左栏「修复」→ **修复选中的坏面（内核驱动）**。
- 右栏新增 **「修复对照」** 页，显示该次修复的网格哈希、拓扑不变量前后差值、
  面积/体积变化、保留/删除/新增面（坐标键计数），以及画布上高亮的“问题位置”。
- 失败（超限、选错面、过期索引）不会静默：错误文本回到修复面板与对照页，
  并校验网格哈希未变。
- 命令行仅作辅助：`scripts/strategy_experiment.py` 复算实验，
  `scripts/window_drive.py` 在离屏环境驱动真实窗口并截取前后对照
  （`artifacts/strategy/20_pick_before.png`、`21_pick_after.png`、
  `window_run.json` 记录组件数 1→2、面数 24→24）。

快速验证：

```bash
LD_LIBRARY_PATH=... QT_QPA_PLATFORM=offscreen python3 scripts/window_drive.py
```

## 基准件

菜单「基准」可现场生成，也可导出为 STL（`artifacts/benchmarks/`）：

| 基准 | 构造 | 验证点 |
|---|---|---|
| `thin_wall` | 两层间距 0.4、厚 1.0 的闭合板 | 邻近点被报告但不焊接；任何自动路径都保持 2 个组件 |
| `duplicate_faces` | 盒体 + 2 同向重复 + 1 反向重复 | 重复面检测与清理；连带非流形边消失 |
| `holed_plate` | 闭合板 + 小破损孔（周长 8）+ 大设计开口（周长 48） | 只允许补小孔；大开口被默认限制拒绝 |
| `mixed_orientation` | 朝外盒 + 整体朝内盒 | 识别朝内组件；翻转后体积增大、另一组件不受影响 |
| `open_shell` | 缺顶面的盒 | 开放边界被检出；朝向标记为待确认，不自动补 |
| `combined_stress` | 薄壁 + 重复面 + 反向面 + 朝内组件 | 全链路修复后复核干净、组件数不变 |
| `multi_hole` | 4 处小破损 + 2 处超限破损 | 路线 A 补小洞、拒大洞；路线 B 整体不落地 |
| `nonmanifold_junction` | 两封闭盒仅沿一条棱相交 | 拆分保面、保面积/体积，组件 1→2 |

## 测试与核对

```bash
# 几何内核 + 集成测试（无 Qt 图形库时 UI 测试自动跳过）
python3 -m unittest discover -s tests -v

# 带图形库跑全部（含 8 项真实 UI 交互测试）
./scripts/run.sh --help 2>/dev/null || true
LD_LIBRARY_PATH=... QT_QPA_PLATFORM=offscreen python3 -m unittest discover -s tests -v

# 基准核对：逐件检测→修复→复核，写出 artifacts/benchmark_report.json
python3 scripts/benchmark_audit.py
```

测试覆盖：单位换算、各缺陷检测、薄壁安全（焊接拒绝/组件保持）、补洞大小限制、组件翻转、绕向修复、撤销/重做、失败操作不改动网格、复核遗留问题上报、指纹在重新加载后仍然匹配、STL/OBJ/PLY 往返、损坏文件拒绝，以及离屏 Qt 下的列表选择→画布选中→修复→撤销→复核→导出→重载溯源全流程。

## 已知限制

- 渲染为软件光栅（画家算法），用于定位而非精确遮挡；超大面数时交互会变慢。
- 补洞使用耳切法，仅接受近平面、简单多边形边界；曲面开口会被平面偏差上限拒绝。
- 非流形边/顶点可按面扇与边拆分（保面、不改坐标），但拆分只改连通性：可能引入重合顶点，默认按“待确认”处理，不自动焊接。
- 策略实验中的“全有全无”路线在超大网格上会放大“什么都不做”的代价；阈值未校准，见 `artifacts/strategy_experiment_notes.md` 的待验假设。
- 单位不来自 STL/OBJ/PLY 文件本身，需在界面中选择；阈值按物理长度换算后参与判定。
