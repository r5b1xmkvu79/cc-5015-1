# 网格修复策略实验

本目录记录两种缺陷处理路线的取舍，并把结论落到可运行的原型与可复算的数据。

- 复算入口：`python3 scripts/strategy_experiment.py`
- 数据：`artifacts/strategy_experiment.json`、`artifacts/strategy_experiment.md`（由脚本生成）
- 内核：`mesh_repair/core/strategies.py`，不变量：`mesh_repair/core/invariants.py`

## 两条路线

| | 路线 A：直接改局部连接 | 路线 B：先建有效拓扑再修补 |
|---|---|---|
| 顺序 | 逐个缺陷就地最小改动 | 先拆交汇、清点全部环，再统一修补 |
| 补洞语义 | 能补的逐个补，超限的保持原状 | 只要有一个环超限，整体不落地 |
| 失败影响 | 已完成的部分保留，可撤销 | 修补阶段不动网格，哈希不变 |
| 适用 | 多洞、只关心可交付部分 | 要求交付物绝不半成品 |

两条路线共用同一个非流形拆分内核，都不删除任何非冗余面。

## 重复面

重复面是冗余副本而非额外面片。两条路线都只删多余副本、保留最低编号面；
若按“交汇”去拆，会把重复保留成合法拓扑，因此路线 B 先清重复面再建拓扑。
证据：`multi_hole` 与既有 `duplicate_faces` 基准中 `removed_face_keys == 0`（除冗余副本外）。

## 裂口与多洞

`multi_hole` 基准有 8 个边界环：4 个小洞周长 8（默认限制内），2 个周长 16、2 个周长 20（超限）。

- 路线 A：补 4 个小洞，面 F `2448 → 2456`，边界环 `8 → 4`，超限洞原样保留。
- 路线 B：清点 8 个环后因 4 个超限而整体放弃，F 与哈希均不变。

数据见 `artifacts/strategy_experiment.md` 的 `multi_hole` 小节。

## 非流形交汇

`nonmanifold_junction` 基准：两个封闭盒仅沿一条棱相交。

关键结论：**只拆边不够**。边的多个入射面拆开后，两个面扇仍共享端点，组件数不降、
并会留下不该有的边界。正确顺序是按面扇复制顶点、再拆边：

- 面 F `24 → 24`（零删除），面积 `1200 → 1200`，体积 `2000 → 2000`
- 非流形边 `1 → 0`，非流形顶点 `2 → 0`，组件 `1 → 2`
- 两个闭合组件各 12 面、体积 1000

这意味着“处理边界”是：非流形交汇能被完整分离，但必须同时处理顶点面扇；
仅拆边会把问题从非流形边变成非流形顶点加边界裂口。

## 属性保留与失败可逆性证据

- 属性保留：`attribute_delta` 以坐标键多重集比对，顶点重排不影响计数。
  非流形基准 `preserved_face_keys=24, removed=0, added=0`。
- 失败可逆：路线 B 在超限时返回与输入完全相同的哈希（`hash_before == hash_after`）；
  路线 A 的每一步都是 `RepairSession` 记录，可 `undo_until` 回退。
  生产接点（`mesh_repair/core/production.py`）在拒绝时也校验哈希未变。

## 待验假设

以下假设未被本实验证明，单列在此，不能作为结论使用：

1. 非流形交汇按“面扇 + 边”切分总能收敛；嵌套/多重交汇的收敛上界未证明，仅有轮次上限。
2. 以坐标键多重集作为属性保留的代理，对坐标被微调（而非重排）的修复会误判为“删除+新增”。
3. 路线 B 的“全有全无”在超大网格上会放大“什么都不做”的代价，本实验未给出阈值。
4. 补洞限制（周长/段长/平面偏差）的默认比例来自少量基准，未在真实资产上校准。
5. 拆分后共享端点变为重复坐标点，是否应再焊接需由用户确认，本实验默认不焊。

## 已知边界

- 设计开口与破损开口外观相同：两条路线都不会自动放宽限制。
- 内腔/模具的朝内组件仍需人工确认，不由策略自动翻转。
- 拆分只改连通性，不改坐标；它可能引入重合顶点，默认按“待确认”处理。
